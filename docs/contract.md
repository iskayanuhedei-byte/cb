# Referral Ads implementation contract

WordPress plugin slug: `referral-ads`. PHP 7.4+, WordPress 6.2+. Vanilla JS/CSS; no runtime package dependency. Admin UI Indonesian. Never automatically click another element or advertising link.

Admin boot global `window.RFA_ADMIN = {config, ajaxUrl, nonce, version}`. Save via POST `action=rfa_save`, `nonce`, JSON string `config`; WordPress returns `wp_send_json_success({config})` or error `{message}`. Frontend boot global `window.RFA_CONFIG = config`; server only enqueues enabled active configuration outside admin/feed. No jQuery requirement.

Configuration: `{enabled: boolean, referrers: string[], debug: boolean, campaigns: Campaign[]}`. Empty referrers MUST block all ad rendering. Only `document.referrer` determines qualification. Match exact hostname or a real subdomain, not substring. Allowlist accepts hosts, optional URL pasted normalized server side; no wildcard support needed. Referrer rules global for every campaign.

Campaign fields:

- `id` stable safe string; `name`, `enabled`, `format` (`banner`, `sticky`, `native`, `interstitial`, `popunder`).
- `headline`, `description`, `label` (default `Iklan`), `buttonText`, `imageUrl`, `imageAlt` plain text/media URL. No raw HTML/JS allowed.
- `linkMode` (`direct`, `parameter`), `directUrl`, `parameterName` default `ad_url`, `allowedLinkHosts: string[]`, `forwardPage: boolean`, `sourceParameter` default `source_page`. Parameter mode reads destination URL from query string of CURRENT page, falls back to directUrl. Allowed parameter destinations: current hostname, directUrl hostname, configured allowedLinkHosts, including proper subdomains. URLs only HTTP(S); relative allowed. ForwardPage optionally adds current page URL as the sourceParameter to the final URL using URL APIs. Links open new tab with sponsored noopener noreferrer.
- `width` number default 728 (range 120..1600), `height` number default 90 (range 50..1200), `responsive` boolean default true, `stickyPosition` (`top`,`bottom`). Dimensions apply banner/sticky, responsive prevents viewport overflow. Native/interstitial/popunder card layouts can use width as max-width and auto height. Sticky/interstitial must always include close button. Popunder is an explicitly labelled CTA opening a new window from a real user click; background positioning is browser-dependent and never guaranteed. No background global page click hijacking.
- `placement: {type: 'css'|'xpath'|'id'|'name'|'class'|'attribute'|'text', value: string, attribute: string, textExact: boolean, tags: string, insert: 'before'|'after'|'append'|'prepend'}`. Default css value `main, article, .site-content`, insert `prepend`; attribute field defaults `data-testid`, independent of campaign name. Match all candidates and use first visible enabled Element. CSS/XPath errors are caught without aborting other campaigns. For inline/native/popunder a missing target renders NOTHING; observe/retry until timeout. Sticky/interstitial placement not required. Text tags comma-separated CSS selectors default `button, a, div, section`.
- `pageMode` (`all`,`include`,`exclude`), `pages: string[]` path patterns: exact path, ending `*` prefix. Match current pathname only. `devices` (`all`,`desktop`,`mobile`) mobile max 767px. `delay` ms default 500 (0..60000), `timeout` ms default 15000 (1000..120000), `closeDelay` seconds default 0 (0..30), `frequency` (`page`,`session`,`always`) default `page`. Page means one insertion per campaign in this document; session uses sessionStorage after successful rendering; always allows each page load, no repeatedly reopening closed ad in same document. Storage denial must degrade gracefully. Delay MUST be respected even if DOM mutates earlier. Timeout ends observers/retries. `requireVisible` boolean default true for placement.

Frontend classes start `rfa-`; each rendered root has `data-rfa-campaign=id`, `data-rfa-format=format`. Lifecycle timers, mutation observers released after placement or timeout. Native anchors/card own DOM; no mutation of matched element's original handlers. Scoped CSS.

Source ownership: root agent PHP, docs/package/environment. Frontend agent `assets/frontend.js` + `assets/frontend.css`. Admin agent `assets/admin.js` + `assets/admin.css`. Test agent `tests/frontend.spec.cjs` and independent browser tests only (coordinate when source ready). Avoid edit overlap.
